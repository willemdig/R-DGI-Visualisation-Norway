This repository contains CSV files based on tables from annexes in publicly available OECD reports. The data has been lightly modified for analytical purposes — specifically, the OECD average row was removed.

All rights remain with the OECD.  The files are shared for non-commercial, analytical use only. The contents do not represent the views of any employer and are not affiliated with any organization.
